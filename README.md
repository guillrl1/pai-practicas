# Programación de Aplicaciones Interactivas (PAI)

Prácticas y ejercicios de la asignatura Programación de Aplicaciones Interactivas del Grado en Ingeniería Informática de la Universidad de La Laguna (ESIT).

## Tecnologías

- Lenguaje: JavaScript (Node.js)
- Calidad y documentación: ESLint y JSDoc
- Gestión de dependencias: npm

## Contenido

- `Jutge/`: soluciones en JavaScript a problemas del Jutge (palíndromos, intervalos, Collatz, medidas estadísticas, sumas de dígitos, entre otros).

## Ejecución

Desde la raíz del repositorio:

```
node Jutge/P80660_Collatz.js
```
