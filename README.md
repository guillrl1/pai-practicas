## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** JavaScript (Node.js / Entornos Web)
* **Entorno de ejecución:** Node.js (V8)
* **Herramientas de calidad:** ESLint, JSDoc
* **Gestión de dependencias:** npm

## 📂 Estructura del Repositorio
El repositorio se organiza por sesiones o proyectos de laboratorio:
* `practica-XX/`: Código fuente de las prácticas evaluables.
* `ejercicios-clase/`: Pequeños scripts y problemas de lógica (Jutge, Kattis, etc.).
* `docs/`: Documentación generada automáticamente o apuntes.

## 🚀 Instrucciones de Ejecución
Para ejecutar cualquiera de los scripts de Node.js, utiliza el siguiente comando desde la raíz del directorio correspondiente:

```bash
node nombre-del-archivo.js
