Class CoordinateSystem

Description

Clase CoordinateSystem para convertir coordenadas matemáticas a coordenadas de canvas. Proporciona métodos para obtener los límites del sistema de coordenadas matemáticas, así como métodos para convertir coordenadas matemáticas (x, y) a coordenadas de canvas (cx, cy).
